# ⚔️ Solo Levelling – Task & Mission Tracker

A **gamified productivity app** where users complete tasks, level up, and stay motivated — inspired by *Solo Levelling*. Powered by **React**, **TypeScript**, **Supabase**, and **OpenAI** for intelligent suggestions and dynamic task generation.

> Built using **React + TypeScript + Supabase + OpenAI**, deployed via **GitHub Pages**.

🌐 **Live Demo:** [Click to Visit](https://your-username.github.io/Solo-Levelling/)

---

## ✨ Features

- ✅ Create, manage, and complete daily tasks and missions
- 🧠 Smart mission suggestions using the **OpenAI API**
- ⚔️ Level up as you complete tasks and track your progress
- 🔐 Authentication via **Supabase** (Email + Google OAuth)
- 🎨 Clean, responsive UI using **Tailwind CSS**
- 📦 Deployed with proper routing support on **GitHub Pages**

---

## 🛠️ Tech Stack

| Category         | Tech                                                  |
|------------------|--------------------------------------------------------|
| **Frontend**     | React, TypeScript, Vite                                |
| **Backend**      | Supabase (Auth + Database)                             |
| **AI Integration**| OpenAI API (mission suggestions, completion tips)     |
| **Styling**      | Tailwind CSS, ShadCN UI                                |
| **Icons**        | Lucide React                                           |
| **Routing**      | React Router DOM with HashRouter (for GitHub Pages)    |
| **Deployment**   | GitHub Pages                                           |

---

## 🧠 How OpenAI is Used

- Generates task suggestions based on user focus
- Recommends mission titles or objectives
- Motivational tips when users complete levels

> Requires an `OPENAI_API_KEY` set in your `.env` file.

---

## 🔐 Authentication

- Email/password login and signup
- Google OAuth with Supabase
- Real-time auth state management and route protection
